# 可选审片工作台集成约定

本包没有部署同步器、Web 服务、自动拼接服务或 SSH 配置，也不包含平台密钥。仅当当前用户提供目的地、允许素材外发并有可用适配器时接入。默认生成结果留在项目内；不沿用其他客户的“自动上传”“自动完整预览”授权。

建议适配器消费 [交付清单](delivery-contract.md)，按 request_id/revision/sequence 标识素材，并以文件 SHA256 绑定审片结论。先传完整媒体，再原子发布元数据；上传开始不等于远端可播。生产 pass 与人工 pending/approved/rejected 分开，不能覆盖人工意见。

同一需求多素材可按用户要求形成合集；collection_expected_count 按交付文件数量而不是生成任务数量。全部成员齐备、顺序1..N、身份和技术检查通过后才标 collection_complete。候选允许待业务审片，但不能掩盖已知关键失败或把齐备当生产通过。修订/缺段/退回后撤销旧完成信号，保留历史记录。

若集成实现完整预览：根据有序 SHA 和算法版本缓存；不把预览再次扫描为独立素材；核对总时长、全片解码、音轨、顺序和独立播放。短段 AAC 直接串联可能出现时间戳问题；使用受控音频时间线并重新编码前保留原文件，实际验证后再发布。这里只是接口与质量约定，当前包不自动合成或上传。
