# 镜头设计：先判断是否切镜，再拆生产任务

所有素材先用下文判断切镜与任务拆分；多角色接力、握手/试用反应、连续剧情、长对白或反馈分镜不足时，再使用后续详细分镜流程。普通单镜不机械增加反打和特写，也不把减少镜头数当作唯一目标。

先用 [整体自然表达](natural-expression.md) 区分动作本身慢、剪辑拖沓和播放设置错误；本文件处理分镜与剪辑。

## 先决定是否切镜（所有素材适用）

分清三层：观众看到的**镜头**、后端执行的**生成任务/job**、用户复用/审片的**交付素材**。一个job可生成多镜，一个连续镜头可能因能力限制需要多个job；两种映射均不自动决定前台文件数。“只做素材”不是“每个动作或句子都独立成文件”。用户明确指定独立动作版/口播版等复用用途时仍按要求分别交付。

| 判断依据 | 制作选择 |
|---|---|
| 同人物、同空间、时间连续，动作自然引出反应或对白，单镜能清楚表达 | 优先一条连续镜头试产；如取物→接住→看商品→转向镜头说话，可同镜完成 |
| 需要展示远景看不清的接触细节、听者反应、空间转换，或明确要求按原片切镜 | 设计有信息价值的特写/反打/转场，写清为何切以及动作和声音怎样接；连续不等于全程固定远景 |
| 用户明确要求不同剪辑用途、独立版本或可单独复用的素材 | 按用途交付，即使共享角色/背景也不擅自合并 |
| 实际路由时长/条件限制，或整段试产已出现可复现的关键失败 | 优先检查兼容路线；确须拆时记录限制/失败证据、连续边界或合理切点及最终素材映射 |
| 仅因句号、无声转有声、动作转口播、先生成了哪张图、端点名称不同、想方便排队/重试 | 不足以拆分；回到完整动作与表达重新设计 |

先估算正常速度下动作、反应和对白的**实际重叠时间线**，再核查路由可接入的条件、时长和质量，不把每个动作时长机械相加。整段在标称时长范围内只是可试条件，不保证动作+对白同时正确；也不能默认它做不到而预拆。对白开始于角色有表达动机的时刻，不要求所有手势先做完、停住后才能说。保留接物缓冲和必要呼吸，不人为给每个job加收尾定格及重新开场。

在现有计划补最少的决策信息：`shot_id / 完整动作-表达单元 / cut_reason（连续则无）/ generation_jobs及拆任务原因 / delivery_clip_id`。无必要切镜且无技术证据时先整段试产；有意切镜则依据叙事核验，不能为了“无拆分”吞掉关键细节。统一入口是先设计再选工作流，不新增重复计划。

### 案例：蛛丝取物的第2、3段


同类任务优先试“发丝附着→张紧拉回→接住缓冲→看商品→转向镜头自然开口”的一段完整镜头。若确因能力拆任务，必须将同镜头片段接续、精剪并验收成一个可用素材，原始jobs另存；仅把旧两个MP4拼起来，不代表动作、产品或表演已修好。

## 先锁定叙事，再拆生产任务

先定位参考中的目标广告范围，逐镜观察切点及其前后动作；记录参考时间范围，区分实测切点、抽帧近似位置和新设计。长参考中的其他广告不混入。业务补充的新动作关系优先，新增镜头明确为设计，不声称原片已有。

先做两张覆盖表：对白覆盖表（逐句、说话人、一次且完整）与视觉事件覆盖表（谁面向谁、发起、接触、体验、反应、交接）。一句对白可以跨多个镜头；无对白的接话、手部特写、反应和走位也须映射到对应shot_id；一个镜头内可覆盖多个事件，不要求每事件新建一镜。不要用“9句对白=9个固定机位长段”的方式代替导演设计。

每个镜头写明：shot_id、叙事目的、参考依据、预计剪辑时长、景别/机位、人物左右/视线、动作起点→接触或转折→落点、对白/声音归属、与上下镜的切点、所需独立素材、复用/补拍/重生成判断及验收重点。另外区分生成素材时长与最终使用时长；模型最短生成长度不能成为剪辑节奏。

## 接力互动的动作因果

有握手等接触时检查：发起者介绍/伸手 → 对手接话或接近（建立接触对象）→ 接触发生 → 必要的手部特写/体验细节 → 接收者的反应 → 转向下一位。参考已用一个镜头清楚表达的阶段可以合并；不能为了凑数量每阶段强制一镜，也不能为了减少生成次数省掉理解动作所必需的阶段。

特写必须接在已建立的人物关系和动作上，检查左右手、袖色、接触方向、抓握位置与释放状态。反应来自刚才的体验：先看手/接触处，再皱眉、抽手、看向对方，不提前表演结论。下一位出现要有视线、转身、入画或反打承接，不能凭衣服换色瞬间换人。保留业务已认可的表情和身份设计，只修正反馈涉及的覆盖与节奏。

## 剪辑连续和首尾连续不是一回事

同机位连续动作因模型时长拆段，按segment-continuity.md接入真实首尾帧。中景切手部特写、正反打、反应镜头是有意切镜：匹配动作阶段、轴线、视线、时间与声音即可，不要求两帧像素相同。不得把所有镜头绑成同机位长镜头来求“顺畅”，也不能把首帧复制给尾帧造成站桩。

切在动作进行中时，两机位共同表达一次动作，不能各自完整伸手/握手一次造成重复。摄影轴线需要变换时先用中性机位或建立镜头说明空间。没有足够原生像素时，手部/表情特写单独生产，不把双人远景大幅裁切放大冒充特写。每个景别从固定清晰母版建参考，避免反复用上一段退化尾帧传播模糊。

## 节奏预演先于批量生成

用参考关键帧或明确标为占位的分镜图做时间线/animatic，配已授权试读音轨或现有可用对白，检查全段因果和节奏。缺运动的静帧预演只验证镜头顺序、信息和时间预算，不能作为握手/口型/连续性已通过的证据。文档分镜是设计稿，不宣称已经完成动态预演。

按自然语速给台词足够时间，动作、听话、反应可与对白重叠。先删无意义的开口等待、说完站桩、重复伸手、空背景和每段重新开场；不删字、不截尾音，不用全片倍速掩盖分镜不足。接话/手部插镜可先按约0.5–1.2秒预排，人物句子依实际试读确定；这些只是起排值，不是硬性统一时长。保留让表情读得懂的反应时间。

J/L切（声音先入或画面先切）仅在声音来源和说话人清楚时使用。握手特写上可以延续上一镜对白；切到听者时不能让听者嘴动成说话人。所有音频单独标来源、入出点及跨镜关系，避免重复台词、断字或一换画面环境声就断。现有自动合成器只按sequence串联完整文件，不执行独立音轨时间线；用它交付前，需先导出按计划精剪、声音已正确分配的独立片段。需要跨镜混音时先实现并验证编辑时间线，不能只写计划就称已支持。

## 两道验收

生成前：按制作模式核对角色设计和保留项，每个切点有叙事/用途或技术理由，job与交付素材映射明确；参考必要事件与业务反馈均能映射到shot_id；对白无漏/重/错人；镜头有明确剪辑落点和补拍清单。先试一个完整的高风险互动小节（建立→接触→必要细节→反应，是否切特写由信息需求决定），而非只试最容易的单人表情，确认效果再扩展。

生成后：逐镜查动作、对白与原生细节；再用完整精剪时间线正常速度检查每个接点前后和全段节奏。记录reference_coverage、action_causality、edit_continuity、pacing、sharpness的证据与结论，不能用ASR通过、解码通过或顺序播放通过替代。关键镜头缺失、因果断裂、重复动作、无意长停顿时，需求整体的剪辑验收未通过，即便每个独立文件可用。

所有必要镜头和剪辑验收通过后才能宣称整条生产验收完成；当前项目允许的完整候选审片与 collection_complete 使用 [工作台同步约定](workbench-sync.md)，不得把候选齐备等同于剪辑通过。旧版保留诊断，修订另建版本；更新skill或分镜文档不等于已重生成或修好旧片。

### 说话人与听者的画面归属

双人首帧中，当前台词的说话人若只有侧后脸，而听者正脸占主画面，模型可能把嘴型、字幕或表演分配给听者。优先准备能清楚看见说话人口部的中近景，听者可仅以背肩前景建立空间；反打另做安静听话素材，不把先前正在说话、嫌弃或看手的镜头直接冒充新的听者反应。

逐句记录实际有声时间窗，并在这个时间窗检查谁的嘴在动、视线对象及是否意外烧录字幕。ASR字面正确不能证明说话人正确；双ASR的同音误识别也不能直接证明发音错误，需要结合原声核验。出现错人、意外字幕或无法明确声音归属时先隔离候选，再调整机位/参考重做，不能靠无依据换音轨掩盖。

人物在结尾被依次点名时，反应插镜沿用结尾群像的光线、服装与站位视线；名字的声音可以连续跨反应镜头，但听者不跟着说话。保持清晰母版和原生近景，勿用小脸群像的大幅裁切补表情。需要产品持续在场时，反应插镜也属于持续时段，不能因切听者而漏掉已批准的产品展示。

抽帧拼图的容量随真实视频时长和采样频率计算，不能固定行列后默认已覆盖全片；长素材必须核实末尾样本，并单独导出原生末帧。远景向近景推镜也要在实际近景检查角色身份，不能只因首帧对应参考就判整段一致；发生面貌或服装漂移时，改用同一清晰母版的独立景别，并复核接点。

## 多角色错配与画外旁白

角色接触后换人抱怨、再切回施动者反应时，先按每句有声区间记录声音身份（谁）、画面主体（谁）、嘴部应说/听/静默与动作责任。前景角色并不自动是声音主人；画面出现被比较角色时，介绍产品的英雄也可继续画外讲解。不要把第一人称旁白误配给当前画面中的比较对象。

提示词已写“off-screen/其他角色不说话”但成片仍错口型，视为条件方案失败，不靠增加同义禁令扩散生产。根据原片切镜拆开介绍、受触者抱怨、施动者无声反应；每段先固定一个说话主体和明确口部可见的机位，再按原片动作阶段剪接。抱怨可以跨无声反应镜头，但只能延续原抱怨者的声音，不让反应角色重新说一遍。

画外解说反复引发嘴动时，将画面动作与声音分开制作：画面不放解说台词，保留眼神、身体和动作反应；配音用已获授权、角色身份与上下句音色相符的声音，保存来源、精确入出点。静音不能去除已生成的错误嘴动；发现残留跟读须重做画面。无声也不等于面部定格：不适可由皱眉、避让和手势表达。验收同时查声画归属、接触先后与空间连续，不只识别文字。

走位有误时分别记录主体位置、脚部支撑、头/躯干倾斜和手臂局部动作。原片只是伸手接触时，不应让整个角色滑向对方；抽手、挥手拒绝、挠自己的头是三个不同动作对象。跨镜固定施动者、受动者、观众视角左右及接触状态，防止重复触碰或角色互换。

同一候选被多个需求复用且收到负面反馈时，按SHA/实际来源追踪受影响需求，只撤销这些引用的完成状态；修正版必须分别核对产品身份、台词及前后镜，不能因为同源就自动当三条均已通过。


## 行走与脚底滑移

人物进场、退场、追随或接近时，单独核对步态与地面关系。先区分镜头推拉、角色真实位移及原片刻意的滑行/漂浮；不是所有位移都应加走路。原片确为步行时，记录起步脚、交替顺序、摆动脚离地、支撑脚落点、身体越过支撑脚和停步承重；用地面固定纹理/影子作为参照，不能只看脚在屏幕上的坐标。原片没有可辨足部细节时，不声称已确认具体步态。

远景小人物可能被模型当作静态物体平移/缩放；近景脚交替变化也不能反证先前远景正常。检查所有实际位移区间，尤其远景进入、切近和停步，必要时密集取帧覆盖至少一个完整左右交替周期。支撑脚着地时明显滑移、两脚固定却身体前进、原地踏步但主体靠缩放前移，或靠镜头推近伪装走近，均记录为失败，不以对白/解码通过覆盖。

原片需要走路而多人物对白与行走同段生成失效时，可将对话建立镜头和全身走近镜头分别生产，保留原空间方向、动作目的和切点；行走镜头只接正确的画外声音，画中角色不跟读。必须有可见迈步、落地、重心转移及自然摆臂的动态条件或实测结果；只追加“自然行走”文字不是修复证据。脚部出画时注明无法核验，不能通过裁脚、遮挡、加速或平移贴图隐藏滑步。保持角色及清晰母版，重做后再检查完整前后镜。


同一开场反馈的进一步约束：如果原片是在前景对白期间让背景人物持续走近，不能为避开小人物滑步而直接删除背景角色，再靠切到近景冒充持续接近。检查两个独立结果：脚步/承重是否成立，以及相对固定前景/地标的距离是否确实缩短；二者缺一不可。切镜前后的主体尺度、路径、步态阶段须连接同一次接近，不能靠切镜突然放大。拆镜只是生产方法，不授权删去同时发生的叙事事件。把远到近的起终尺度和时间窗写入事件表，并与原片对照，而非把“迈步了”写成“走近验收通过”。
