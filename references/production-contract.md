# 参考、造型、表演与实际条件的统一约定

用于有参考的改造、人物表演、复杂动作和连续分段。与现有 plan/分镜共用一份记录，不额外复制多套清单。原片的表演与镜头证据先于提示词；输出好看、关键词齐全或对白正确，都不等于参考还原。

## 1. 改造范围先锁定

先按 [投流角色优化](paid-ad-character-design.md) 判断制作模式：依据当前用户的复刻、局部替换或创意改编要求选择模式，不继承其他项目授权；明确保留的维度仍优先。在需求计划内记录制作模式及依据、record_id、需求日期、原片路径/SHA和使用范围，并按以下维度区分“保留／用户授权修改／尚无证据”。新反馈更新受影响的维度，不自动重设计其他部分。

| 维度 | 要明确的内容 |
|---|---|
| 人物与造型 | 身份/年龄范围、发型、服装轮廓与材质、妆发、整体气质；换脸不等于换情绪和动作 |
| 表演与声音 | 角色关系、说/听轮次、情绪变化、重音与停顿、原声或已锁定的声音来源 |
| 动作与镜头 | 起因、接触、路径、方向、速度变化、结果、构图和切点 |
| 场景与产品 | 获准改动的场景元素、实际SKU、道具来源、尺寸依据、手持关系、场景受光与品牌色；分别验绝对合理性和跨段一致性 |

“只换产品、其他不变”等排他要求按原意执行；“花店改超市”只是场景要求，本身不禁止默认的投流角色优化。换人物不改变角色关系，未被改编的关键镜头、动作机制和反应仍要保留。只有图片的参考不推断完整运动，获准原创的部分标为设计。缺失事实先利用已下载来源补查，只有影响执行且无法确定的事项才问用户。

自然度与审美分别控制：自然是可信的反应、身体协调与真实质感，不等于宽松家居服、素颜或普通长相。用户要时髦、性感的成年人物时，把要求具体写成合适场景的服装剪裁、材质、妆发、配饰和自信气质，保持非露骨呈现；不要擅自改成居家风。其他已允许角色优化的投流需求可主动优化角色，但不统一套性感风；具体审美由需求、受众线索和竞品类型决定。母版先验造型和剧情初始情绪，再用于视频。

## 已选素材先理解表达用途

读取需求与分析竞品是本生成流程的原有职责；在既有计划里说明“这条需求要表达什么、参考的哪部分支撑它”。选材候选排名属于独立选材流程，不在这里另设选材门槛，也不以创意偏好替换用户已选参考。

- **分别标明每份参考的用途与区间**：可能借人物关系、分屏格式、某次动作、情绪变化、数量感或产品展示，而不一定借整条内容。一个需求有多个参考时分别对应，不把所有参考混成单一造型母版。明确“前两镜”“某秒以后”时取指定范围；同一文案字段若包含多个独立广告，也先识别各自用途，不硬串成同一时间线。
- **把想保留的表达与要改的外形分开**：例如用户要求保留“买/不买”分屏、改家居手机场景，需保留购买分歧与递进回应，不能继续复制原超市场景。跨品类开箱参考可借数量展示，冰块可借清凉联想；原品类的成分、功效和包装不随动作一起迁移。
- **把台词意义落实到可见事件**：问者为什么追问，答者解释了什么，听者如何从怀疑到理解，商品在何时参与。以“倒出产品时说话”为要求时，倒出和说话要同步；把两个动作分别生成后串起来并未完成原意。表演强度、语速和有依据的停顿同时考虑，不把紧凑等同于全程加速。
- **按用途保持范围完整**：只要开场、感受画面或解释段时，不擅自追加优惠、CTA或全片内容；要求完整创意时保留相应信息链。用于剪辑的组件化选择不等于将连续动作机械拆成每句一个文件。已确认文案照原范围执行，不因觉得更适合投流自行删改。
- **使用当前任务的角色与商品依据**：不同需求可能分别要求保守穿着、重设计人物或保持品牌人设；单条造型不固定成全批偏好。产品字段、正文和实际图冲突时明确定位，不能仅按字段名换盒；历史价格、数量和功效措辞未核实前不当作新任务事实。

这一步形成可执行的目标事件、说听关系、改动范围和商品依据，再进入下列生成方法。原片只抽帧时记录证据限制，动作时序和表演节奏仍须动态核对；不得凭选材理由宣称成片或投放效果通过。

## 素材类型决定生成方法

下表用于识别能力与风险，不用于划分文件。同一连续镜头可以同时包含入场、取物、反应与口播。先按 [分镜与拆分决策](storyboard-editing.md) 确定自然表达单元，选择能覆盖整段所需动作、声音、时长、身份与清晰度的路由；不能因功能名称不同预设多个镜头。

| 镜头类型 | 优先做法 | 代表试片必须暴露的风险 |
|---|---|---|
| 真人采访/口播 | 先定交流对象、回答目的与语气，再选适合开场的造型母图；按完整表达设计而非每句排表情；原有单镜成立时保持单镜 | 语义、表情、声音与身体是否表达同一意图；既不僵硬也不持续乱动；商品自然融入 |
| 双人/多人口播 | 先排说话人与听者、左右和声音，复杂轮次用原片有依据的正反打/反应镜头 | 完整问答及接话，听者不跟读，声线不互换，台词不跨角色 |
| 走位/入场/接触/取物 | 起点、路径、接触、缓冲、终点与镜头一起设计，按实际节点能力接入运动/边界条件 | 从准备到结果的完整动作，不能只试拿到商品或站定的结尾 |
| 多段连续剧情 | 先分镜和剪辑预演，再按真正连续边界或有意切镜制作；声音可跨镜 | 相邻两镜的同一次动作及反应；禁止每段重新开场 |
| 包装/材质/手部展示 | 实际SKU为外观基准；简单展示避免冲突旧包装输入，复杂手部保留完整接触依据 | 结构、文字、遮挡、尺寸和中间转动，不只查首尾颜色 |
| 平面产品替换且原动作可可靠跟踪 | 经验证的跟踪/遮罩/关键帧合成可保留原运动；检查透视、边缘和遮挡 | 完整交互周期和所有方向变化；固定贴图不冒充立体手持 |

弹射、摆荡、腾跃等高动态入场还须读 [参考还原](reference-fidelity.md) 的高动态分支；按原片的风格化速度/幅度设计，不套日常小动作。新需求按镜头选择，不先决定全部用一种端点。保留原片的合法可复用画面与已认可素材时，核对当前授权、身份、动作、版本和质量；只修局部无需整条换人或重绘。无法保证的复杂动作不默认简化成静物或自由飞行。

## 2. 先设计交流目的，再设计表情

人物镜头在生成第一张母图前完成这一步，写进现有角色/镜头计划。用一小段话说清“此刻对谁说、想让对方理解/相信/做什么、自己处于什么状态、什么信息使状态变化”，再决定观众必须读到的表现；纯动作或无人产品镜头不硬填内心戏。不要先把漂亮人物图生成好，再临时往静态姿势上堆表情。

| 计划要作出的决定 | 落到镜头上的作用 |
|---|---|
| 交流对象与目的 | 区分向朋友分享、回答陌生采访者、求证、反驳、逗对方等；决定目光对象和语气，不统一对镜头营业 |
| 起始状态、信息变化与情绪方向 | 明确人物已知道什么，转折为何发生；惊喜、怀疑、得意、尴尬各有含义，不默认每句递增到大笑 |
| 观众必须读到的表演 | 选能支撑语义的反应，强度与参考、角色和景别相称；不要求每个身体部位都动，不省略关键嫌弃/疼痛等结果 |
| 声音和时间依据 | 准确台词、说听归属、承重意群与有依据的停顿；表情和身体随交流组织，别另排一条与语气无关的动作时间线 |
| 母图、景别与实际条件 | 初始情绪/视线是否适合开口，口部和所需身体动作是否可见，道具能否操作；所选工作流究竟连入图、音频还是视频 |

参考的动态与语气是生产输入。表演为核心时，先使用可用工具查看指定区间的原速互动并试听；抽帧定位细节，转写核对文案，不能把两者当作表演分析完成。条件不足时记录已知事实、缺少的依据与本次设计推断，利用已授权的素材继续补查；按客户允许的原创改编/候选流程继续时，明确采用原创表演设计，不能暗称照原片还原。承认缺证据并不能让随手补的动作变成可靠设计。

在原有事件表里保留“原片区间/事件—角色获知的信息—交流目的与状态变化—可见/可听依据—目标意群/镜头—实际差异”。只标实际观察到的时间，改编的反应另标设计。新台词较长时按正常语速安排，与动作可合理重叠；不能把每个眼神、转头、微笑串行相加，制造开口慢和一拍一动作。

听者可在对方说话时逐渐理解并开始反应，回答接续依语义和参考；不要求每次都“听完→停顿→做表情→开口”。确实依赖接触/新信息的结果不能提前，角色也不能抢另一人的台词。情绪可以延续、转向、克制或短暂增强，不必每镜都有峰值和笑容收尾；节奏与表演细则见 [整体自然表达](natural-expression.md#三人物表演按交流意图设计)。

生成前把计划代入完整镜头作一次纸面走读：没有那些“自然/生动”形容词，是否仍知道人物在交流什么；必要反应是否拍得到；声音、初始图与意图是否一致；正常语速是否容得下完整事件。发现矛盾就在生图/提交前修正，无须额外审批或新建评分表。走读能发现设计缺口，不能证明模型会一次成功；试片和验收仍用于验证实际输出。

## 3. 复杂动作保留机制和镜头表现

记录完整“准备→触发→传力/移动→接触→缓冲→稳定”，同时标明主体与镜头各自的运动。原片的远到近、仰俯角、主体画面占比、追随/推进及切点属于动作效果，不能统一改固定全身机位。不要将拍摄运动误作角色位移。

蛛丝取物要区分两条因果链：人物借锚点摆荡入场；蛛丝附着商品、张紧牵引、空手接住。分别核对锚点/附着点、弧线或拉回路径、先后时机、加减速、手肘回收、抓握遮挡与缓冲，原位置商品离开后不能残留副本。有蛛丝和拿盒终点不等于动作还原；首尾两张图不能证明中间传力成立。换超市场景可以调整合法落脚和货架位置，但不能省掉原片入场景别变化。

出拳、握手、行走、取物同样按因果链验收：方向有对应，支撑脚与身体位移相符，道具先有来源再到手里。无法在一段中可靠完成时按原片合理切点分镜，保留中间动作镜头，不靠突然切到结果掩盖缺失。

## 4. 分清三种参考，核对实际接入

- 原始视频：表演、动作、节奏、镜头的事实依据。旧生成视频不能取代它作为还原标准。
- 已批准的清晰角色/产品母版：身份、造型和材质基准。剧情情绪可以变化；海报式笑脸不是全片表情模板。
- 上一段最终剪辑尾帧：边界的站位、视线、手势、道具尺寸和运动阶段。它不授权下一段照搬上一情绪，也不应作为全组唯一画质参考。

计划记录实际端点/工作流、连入的条件类型及对应文件。多图reference不等于硬首帧/尾帧；把“exact continuation”写进提示词也不能改变节点能力。端点缺所需条件时改用已验证可用路线或合理切镜，并保留限制说明；fast只缩短等待，不降低此要求。声音参考与边界条件有取舍时先试完整接点，不静默牺牲连续性。

清晰母版保持固定，尾帧逐段重新验收。眼睛闭合、脸型漂移、商品放大或失焦的边界先修复/改切点，不能将错误滚动传播。首尾姿态允许随剧情变化；应守住身份、尺寸、空间和动作路径，而非要求两帧看起来一样。

## 声音和画面使用同一角色表

每个角色固定 role_id、批准的外形参考、声音来源与干净采样范围，镜头再记录其说话/倾听/画外音身份。角色是剧情身份，不随画面左右、衣服颜色或第几个音频槽位变化。生成前核对实际音频槽位和对应角色；同一角色后续段不重新随机抽一条声音作为新基准。

声音一致包含声线、语速、情绪、音量与环境声。声纹比对和ASR是辅助，不能证明表情、情绪语气和口型通过。用户要“角色直接说话”时保留该角色画面及可见说话，不擅自插产品图；用户要旁白时允许覆盖动作画面，但画内无关角色不跟读。新声音或裁切改变后检查相邻句的响度、断音和语气承接。

## 5. 提示词只写能落实的镜头指令

按现有 H3 六段式，把已核实约定分配到 Scene（场景关系）、Character（身份与交流对象）、Action（人物的交流目的、关键状态变化及必要物理过程）、Camera（真实景别/运动/切点）、Dialogue（准确文案与角色）、Sound（声音身份及与语义相符的语气）。图片与视频提示词使用同一造型定义。计划用于充分推敲，生成prompt只保留决定表现的指令；不把整份分析、AU表或大量否定词塞入模型。

在现有计划中按镜头保留：`叙事/交流目的 / 原片依据与设计推断 / 不变量与起始状态 / 关键变化或物理动作 / 景别与切点理由 / 声画归属和时间预算 / 实际条件、job与交付素材`。不相关项省略，不重复创建表演表。身份、SKU、空间规则是不变量；表情、手势、取物阶段是应变化的状态。情绪用明确的方向及语义说明，谨慎使用可能同时解释为怀疑和惊喜的 disbelief 等词。

返修时先更新本次计划的版本、反馈与处理理由，再导出实际prompt和条件快照并关联job；历史计划/提交保留，不事后改写成早已执行新版方案。抽帧分析、未试听、没有视频条件等限制也随版本保留。可选第三方适配器不经过 `build_workflows.py` 时仍执行这份约定；文件结构校验不能证明计划已落实或表演优秀。

提交前核对实际发送的 prompt、图片和节点，而非仅检查 plan：有没有又写 loose navy top、全程微笑、固定全身机位、同图首尾或错误商品？模型长度限制不允许时精简非关键修饰或拆镜，不能静默截断动作和对白。

## 6. 比较与交付要使用当前版本证据

试片选择能暴露主要风险的完整互动，包含相关的听者、取物或跨段接点。将原片与候选按相同事件对齐，分别记表演情绪、身体反应、动作机制、镜头、产品、节奏和清晰度的实际差异。抽帧证明静态细节，原速动态观察证明动作，试听证明语气；不会因为某一项通过而替其他项打勾。

发布执行现有 [验收门槛](natural-expression.md) 和 [同步规则](workbench-sync.md)。接入自定义打包脚本时必须核查是否调用当前证据检查；自定义 dialogue_checked、joins_checked 或 product_scale_checked 布尔值不能替代完整检查。检查未运行或失败就没有“验收通过”，不能为生成完整预览填假 pass。当前用户允许候选交付时，按同步约定保留真实待复核项继续工作。文件齐备、生产验收、业务通过分开陈述；候选不得宣称成品合格，后台自动校验未接入时也不能声称已自动拦截。

反馈复修按下面的顺序定位，证据不能区分原因时保持假设，不归咎“模型随机”。

| 实际失败 | 首先改变什么 | 不能靠什么宣布解决 |
|---|---|---|
| 产品过大、过亮、像贴图 | 查实物尺度依据和母版受光，保留品牌色，用近景展示细节 | 与上一错误段保持一样、直接复制电商图亮度 |
| 表情偏离剧情，或造型不符已定制作模式 | 回查允许修改范围、母版初始情绪、逐句表演依据和实际prompt | 再加 natural/beautiful 或换种子 |
| 脚不动却走近、无接触就拿到盒 | 补路径/支撑/接触状态与对应镜头，核对可用动作条件 | 两张好看的首尾帧、遮掉关键动作 |
| 两段之间跳变或商品变大 | 先复查拆分必要性，无理由的连续事件优先改为完整镜头；必要分段再比较边界、修失效一侧并追踪依赖 | 同为24fps、每段单独看都正常 |
| 越生成越糊 | 查原始参考→母版→原生输出→编码的首次退化处 | PNG重存、加码率、反复修脸锐化 |
| 动作慢、节奏散 | 对齐原片事件真实用时与切点，分别修生成动作和剪辑停留 | 全片倍速、统一缩短每镜 |
