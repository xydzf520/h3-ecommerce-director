# 投流素材：角色优化与复刻的边界

本规则按当前任务约束选择模式。仅提供参考并不授权任意换人；用户明确要求创意改编、角色优化或在项目中配置该偏好时，才主动重设计角色。

## 先选模式，再锁角色

- **一比一复刻**：需求明确整条“一比一”“完全照原片”等。保留未授权变更的内容；更具体的换人或换产品要求仍按其范围优先执行。
- **局部锁定**：只要求“人物不变”“声音保持”“动作按原片”等，仅锁对应维度，不把整条升级为一比一。其余维度按当前用户允许的范围设计。
- **投流角色优化**：当前用户允许改编时，根据需求与竞品设计角色。普通“按参考”、只提供竞品、只写场景替换，都不自动构成全维度复刻或自由换人授权；不明确时先保留既有锁定项，仅询问会影响制作的关键范围。
- **局部返修**：延续已经确定的新角色母版，只修本次反馈及其相邻依赖；用户仅要求修动作、表情、衔接时，不重新随机换脸换衣。已有“保持跟原来一致”等明确指令优先。

“只换产品、其他不变”是排他保留约束；“花店改超市”本身不是。收到“和原片差距大”时先定位丢失的事件、情绪、动作、镜头或具体外貌要求，不把整项任务自动转成一比一，也不以“优化角色”为由忽略反馈。

## 需求理解先于角色和镜头

在同一份计划里简要分开三类依据：**用户明确要求**（当前文字、已确认补充及反馈）、**竞品可观察事实**（具体事件/角色关系/动作和情绪）、**本次设计判断**（角色优化、节奏、镜头方案及理由）。需求文字短不等于没有要求，也不等于竞品全部锁死；事实缺失不能靠设计假设补成“原片已有”。冲突按当前明确指令及已持续确认的约束解决，不按标题关键词猜需求。

先锁实际SKU、准确文案、说听身份、关键创意机制和指定不变项；将可优化的人物外形、妆发穿搭、气质和有动机的表演写为具体设计。必须明确本次角色优化了什么及其投流用途，而非只写“更美、更自然”。若需求允许优化且参考造型已经适合，可保留有效部分并说明选择，不为证明换人而随机更换。角色关系/动作职责与演员外貌分别记录；“蜘蛛侠形式”可能指发丝、锚点、摆荡和取物机制，不自动指红蓝战衣或换男性。

制作顺序为：`需求事实与模式 → 角色关系、交流目的与不变量 → 完整动作/表达、镜头和可实现条件 → 造型及开场母图 → 试片 → 发布素材`。人物计划按 [制作约定](production-contract.md#2-先设计交流目的再设计表情) 落实；形象设计与表演目的互相核对，不能只选漂亮静帧再临时补表情。使用 [分镜与拆分决策](storyboard-editing.md)，不得先选“动作工作流/口播工作流”再反推两个镜头，也不将换演员误作重写创意的授权。实际图片、视频和声音条件都与本次计划一致。

## 优化要成为可执行设计

先读取需求和竞品，提炼吸引观看的核心：人物气质、关系反差、开场表情、动作奇观、问题悬念或商品演示。再围绕该核心设计新角色，不直接复用竞品脸，也不默认普通居家风。

在现有 plan 的角色条目内简记：`制作模式及依据 / 受众与场景线索 / 角色气质和辨识点 / 发型妆容服装材质配饰 / 开场情绪→事件触发→反应 / 保留的创意机制 / 新母版路径`。受众未知时从需求与竞品作暂定设计假设并标记，不编造人口统计或投流结论，也不为可逆造型选择逐项等确认。

- 真人：选择适合需求的有吸引力、上镜且有辨识度的成年形象；用具体妆发、剪裁、色彩、材质和气质落实时髦感。性感风仅在需求和情境适合时采用非露骨表达，不将其作为所有视频通用模板。
- 表演：把自信、好奇、调侃、怀疑、惊喜落实到对谁表达、为什么表达和怎样说；表情依交流变化，不把性格标签写成全程固定脸。吸引力不等于持续笑、夸张瞪眼、塑料皮肤或机械小动作；听者也有交流目的，身体表现随情境组织。
- 多人：脸型、发型、穿搭、声线和性格有可读区别，同时保持原有说听关系。不能把角色都做成同一张脸换颜色。
- 拟人/动画：可优化轮廓、五官、比例、服装和表情辨识度；保留角色身份与关系。真实产品包装仍以实际SKU图为准，不能借角色重设计改错品牌、盒型或文字。
- 动作角色：造型应支持跑跳、摆荡、握手、取物等表演；换造型后重新核对手脚结构、服装运动、遮挡和实物尺寸。不能用静态美观牺牲动作路径。

## 面向投流的镜头与验收

让开场尽快出现核心人物、冲突或关键动作，压缩无意义站定和空白；不统一规定每条都要几秒钩子，也不为“快”砍掉触发、接触、反应和必要台词。按手机观看选择能看清表情和商品的景别，必要时设计反应/接触/产品细节镜头；商品保持真实尺度和场景受光，不通过放大盒子、提亮品牌色制造吸引力。

对照竞品的是创意成立的机制与信息覆盖：例如蛛丝远处摆荡靠近、发丝附着商品再拉回手中必须成立；优化脸、发型、穿搭不授权改成自由飞行或商品凭空出现。可根据需求重设计具体镜头和表演，但在计划中说明保留什么、改进什么及原因，不能将生成失败后删动作包装成创意优化。准确文案、角色关系、实际SKU和用户指定细节继续受原有规则约束。

先用能同时暴露造型吸引力和关键表演/动作的代表片验证，避免只用漂亮静帧决定整批。验收分开看：

1. 新角色是否符合需求及投流审美，开场和表情是否有辨识度；按已选模式及新母版判断，合法改造不因与竞品长相不同而失败。
2. 核心事件、卖点、动作因果和角色关系是否完整，表演自然、节奏连贯，人物与商品细节可读。
3. 新母版是否真正进入图片、视频和声音条件，整组身份、造型、声线、尺度与清晰度是否一致。

主观吸引力待业务审片，点击率、完播率、转化效果须有真实投放数据才可下结论；不能凭“更好看”宣称投流效果已验证。不自动发布广告、改文案卖点或批量生成额外A/B版本。
