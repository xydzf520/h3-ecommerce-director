# 参考视频复刻：先还原镜头，再核对对白

有竞品参考或用户反馈关键细节丢失时使用。先读 [投流角色优化](paid-ad-character-design.md) 区分一比一与默认投流改编；本文件的动作因果、信息覆盖与产品规则两种模式都适用，外貌和衣着原样保留仅适用于明确锁定项。

## 触发条件与处理边界

| 遇到什么情况 | 正确处理 | 进入生成/交付前看什么 |
|---|---|---|
| 明确“一比一/完全照原片”或“只换产品、其他不变” | 保留未被要求改变的镜头结构、人物关系、关键动作、服装设计语言、光线和节奏 | 有原片与计划的逐镜对应，不能只剩相同台词和大致背景 |
| 普通“按参考/参考竞品”，未要求一比一 | 按需求主动优化角色外形、造型和表演；保留关键创意机制与关系，记录改编设计 | 对照需求和新角色母版验收，不能仅因长相/衣着不同判失败 |
| 长视频/合集，文案只对应一小段 | 定位对应片段，按切镜和动作密集取样；不用全片均匀六帧作为依据 | 所有目标台词、主要动作和出场镜头均已覆盖 |
| 文案是一段连续文字，参考却换人/换镜头 | 结合嘴部动作、画面和音频判断各句实际说话人；按可剪辑镜头拆分 | 角色、左右位置、说话人、对白顺序明确；不得把整段分配给一个角色 |
| “男版”或换角色 | 在原片的构图、交互和服装设计上改为所需角色；保留角色之间的区别 | 双人仍是双人、握手仍有握手、反应仍由相应角色完成；不退化为只换衣服颜色的单人口播 |
| 新文案与参考的产品名或卖点不同 | 文字内容按用户确认版本，动作/角色位置按参考；明确旧角色→新角色/产品的映射 | 不按颜色猜角色；不把原片的旧卖点、旧产品名混进新文案 |
| 参考带字幕、角色标签、实物包装文字 | 区分烧录字幕与场景内身份标签、真实包装；分别决定清理/保留/替换 | 清理没有破坏人物服装、关键标签和商品主标识 |
| 发现历史成品或相同SHA的旧原片 | SHA只用于来源/完整性，另外核对旧成品的视觉与当前需求 | 旧成品确实通过本次视觉要求，才能复用；用户已否定的成品不能继续当依据 |
| 握手、接触、双人反应、走位或群像特效 | 选风险最高的对应镜头试产；记录动作起点、接触和结果，必要时拆镜头 | 接触动作、角色关系和出场效果存在且方向正确，不用对白合格替代 |
| 用户指出“不像/差距大/重新来” | 先暂停受影响生产，撤销完成状态、从预览/打包中移出失败版，保留诊断副本；从原片重新建参考 | 有偏差原因和修正后的原片/试产对照，才扩大生产；其他已认可范围不自动重跑 |
| 只有素材ID、截图或无法获取的原视频 | 先解决可访问参考；用户已要求“无参考不做”时跳过并记录 | 不把猜测的动作和内容当成已看过的参考 |

“独立素材”与“每句一个单人口播”不是同一要求。先按 [分镜与拆分决策](storyboard-editing.md) 判断完整动作/表达和复用用途，生成任务边界不自动成为交付素材边界；若用户另行明确简化、创意改编或变更风格，以新要求为准，不强行复刻。

原视频改造同时按 [整体自然表达](natural-expression.md) 记录每个关键事件的参考/候选时间范围和差异。原片对白一样、人物颜色相近或镜头数量相同，均不足以证明复刻。

## 先确认真正的参考范围

合集的均匀抽帧会漏掉短广告的关键动作。先浏览/抽取用户文案对应的完整段落，标记起止，再在这个范围内按切镜、动作转折和说话人变化取帧。对话和手部动作需要连续帧或局部密集抽帧，不能只看整个合集的六张图。

建立简短的镜头对照表：原片时间、角色和左右位置、谁说哪句、动作起点→关键动作→结果、景别/机位、光线背景、服装与材质、出场/特效、目标文案。合集范围之外的广告不混入。文案换了产品名时，按原片的剧情位置映射角色，不凭衣服颜色猜谁说话。

参考母版按“镜头＋动作状态”选择，不能只按人物选一张全组复用。同一个人开场双人景、中段持杯近景、末段空手近景，是三个不同参考状态；锁定人物身份不等于锁死同一构图。对话改文案后，仍须保留对应的听问、回答、视线转换和道具动作；按新文案适配时长，但不要用通用的“小幅自然动作”覆盖已观察到的具体动作。

## 区分参考来源和可信度

优先用当前原视频中的画面。历史生成图只是候选派生参考；必须与对应原片逐镜对照后才可使用。原片SHA相同，只能证明文件相同，不能证明旧成品忠于参考。用户指出不相似后，撤销受影响成品的完成状态；保存失败证据，重新从原片建参考，不继续用失败成品锁角色。

制作复刻图或仅清理参考图时保留已锁定的领口、袖型、材质、饰品、轮廓和背景结构；默认投流角色优化另建清晰设计母版，可改这些造型维度，不把原片清理图当最终角色。避免仅裁脸后让模型自行补服装。区分片头标题、烧录字幕、法规小字和角色服装上的身份标签；不能用“禁止所有文字”一并删掉角色的关键设计。身份标签如需按新文案换名，应明确映射，实物包装按真实产品图。

“男版”通常意味着在原片构图、交互、动作、机位和光线基础上转换角色；不能无依据改成单人站桩口播，或把所有角色做成只换颜色的同一张脸。服装转换保留原片材质和设计语言，按成年男性身形重构。

## 独立素材与镜头拆分

“只生产素材”决定交付为独立文件，不意味着取消双人对手戏、握手特写、反应镜头、走位、聚光出场或群像。按可剪辑镜头拆文件，必要时一个文案单元拆多个独立片段，并维护说话人和台词顺序。不要机械地把每一句都做成面对镜头口播。

同一动作的起点、接触/转折、结束都要有依据。多主体或多阶段动作若单段生成难以稳定，拆为有意义的双人建立镜头、动作特写、角色反应等，保持前后手势和空间方向。

## 视觉验收独立于语音验收

试产选择本任务最能暴露风险的镜头（例如双人握手、细节服装、群像聚光出场），不能用容易的单人口播通过来代替复杂镜头能力验证。先看原片与试产的并排对照，再扩展同类段落。

记录人物/服装、角色关系与说话人、构图/景别、关键动作、镜头节奏、背景光效、产品七项的对照结论。关键动作缺失、单人替代双人、违反已锁定的服装风格、说话人交换、出场特效消失时，视觉项不通过，即使视频能解码且两套ASR全对。技术检查、对白检查、视觉还原必须分别记录。

采用固定取样数量不足以覆盖动作时，加查局部连续帧。不要宣称完整口型验证或人工试听。对生成能力达不到的关键动作，应改变分镜/参考/方法，并如实说明限制；不可把相似度不足的结果标成复刻完成。

## 产品替换与动作联动

适用于“只换包装/产品”和出拳、推拉、碰撞、跟随等存在明确交互的镜头，不要求普通静物镜头额外摇摆。文字需求写得短，也不能省略参考已经表达的动作细节。先分清：文字指定改什么、参考保留什么、业务补充修正什么；用户新确认的动作关系优先。

生产前建立动作事件表，每次交互分别记录：时间/帧号、施动主体、画面中的运动方向、产品响应方向、起动→接触或最近点→最大位移→回位、遮挡层级。统一以观众看到的画面左/右为坐标，不把“左手出拳”误写成“拳头向左移动”；出拳手、拳头运动矢量、产品摆向是不同字段。没有真实接触的卡通动作记录最近点/动作峰值，不伪称碰撞。

双拳动画中，业务确认“向哪边出拳，向哪边摆动”时，产品必须与对应方向和时点联动，回拳/换拳时的回位和转向也要有依据。不能只留下拳头动画，把产品固定在中央；不能只跟踪上下坐标而漏掉横向摇摆；也不能另加与拳头无关的正弦摆动。不得凭经验改成反方向“躲拳”或自行模拟另一种受力逻辑。

对照参考记录并保留以下可见细节：横纵位移、倾斜/转动、缩放或透视、速度与停顿、左右交替次序、动作幅度、前后遮挡、入场和收尾。没有可见旋转时不硬加摇头倾斜；跟踪不到透视时不能声称完整三维复刻。容器换成长盒时，可以适配初始尺寸和接触位置，但不能为适配长宽比把运动幅度清零、裁掉拳头或遮住主要动作。字幕、音轨、背景等按当前交付范围处理，勿擅自恢复参考中的旧品牌文案。

技术上分别跟踪产品与交互主体；固定机位可跟踪产品中心 x/y、稳定边缘和角度，再以共同的时间轴驱动合成。镜头本身移动时先区分镜头运动与产品相对运动。检查跟踪置信度、遮挡和跳点，必要时用人工关键帧校正；不能用宽泛颜色掩膜混入字幕、手部后仍当可靠轨迹。始终从同一张高清实际产品母版做每帧变换，保留透明边缘和包装文字，避免用上一帧反复缩放旋转造成越来越模糊。

验收先选一个完整左右交替周期，按事件表对照原片与成品，局部逐帧核对起动、方向、峰值、回位、遮挡；通过后检查整段所有动作及首尾。固定六七张均匀抽帧、文件可播放、SHA 一致和产品全程存在均不能证明动作正确。动作联动单独记通过/失败及证据；错向、漏摆、提前反应或不同步均撤销视觉通过。


## 本机取帧工具

可用`python <本skill目录>/scripts/reference_frames.py --input <视频> --start <秒> --end <秒> --step <间隔秒> --out <新的审查目录>`。

必须先选择文案对应的起止时间，再运行工具。它导出实际时间戳帧、每8帧一张联系图和frames.json；不会替你判断剧情范围。切镜/对手戏可用约0.5–1秒，手部接触或说话人切换有疑问时用更密的局部区间。不要把固定间隔或取样数量当成完整审查。

经图像工具清理得到的参考仍需与原帧并排复核：去掉了字幕，却改错已锁定的胸前身份标签、领口、手势、机位或脸部时，参考不通过；明确记录的投流角色重设计按新母版验，不当作清理错误。修好再进入视频生成。参考槽位只放该镜头有作用的图，并明确各图角色；无产品镜头不机械附带产品盒图。

## 产品在前后镜头中的连续性

### 原片视频可能把旧产品带回生成结果

H3 的参考视频同时含有外观和动作信息；提示词写“只参考运动”不等于工作流真的隔离了产品身份。即使接入高清实际产品图，也可能开头正确、转动后变回竞品，或先出现竞品再切到新包装。只验首帧、只验末帧、认为颜色相近即可，都会漏掉这种错误。

当原片含不同品牌/不同SKU的清晰包装时，先判断动作是否需要视频条件。手指划过袋面、轻转展示、聚光台小幅运镜等简单动作，可保留原片作为分析依据，用干净实际产品图和明确动作事件生成；不要为了携带运动同时输入冲突的包装外观。复杂握持、遮挡、取出或互动不能机械删掉视频后降为静物：须用身份正确的动作参考、分镜或经验证的跟踪合成保留原动作。没有证据不能声称某个槽位只传递运动。

已发现包装串入时，隔离该版，检查同一受影响条件组合的待执行镜头；只调整本任务明确识别的任务，已运行/已提交任务先查精确prompt_id与队列，不因等待超时重复提交。修正版除了检查实际产品图，还要覆盖所有切镜、转动与遮挡前后，确认没有短暂出现旧品牌/旧SKU。裁掉错误半段只有在剩余部分仍包含完整要求动作时才可采用；不得以裁切或模糊隐藏身份错误。

实际案例：0909锁定批次的手持粉袋试片先出现竞品银袋，持久聚光试片则从蓝袋转成竞品金袋。去掉冲突视频条件后的绒布展示和聚光展示修正版，在已查看的帧序列中保持了实际包装身份。该证据支持简单产品展示的条件选择，不证明所有复杂动作都应改为仅图生视频，也不替代原速观看。

### 产品持续展示

用户指出“前面有产品、后面没有”，或要求全程展示时，先检查提示词/分镜是否主动要求产品移出画面，再判断模型是否违反约束。不要把提示词造成的消失归因于模型随机性。

为每个镜头分别记录前景单片、背景盒等产品的进入/持续/退出安排。背景盒仍在不等于前景单片持续展示。参考片的切镜不能覆盖用户已确认的展示要求；需要持续展示时，提示词写清首帧到尾帧保持完整可见，去掉相冲突的移出画面、杯子单独收尾等指令。可用固定机位单镜头降低风险；用户明确要求产品离场的创意不受此约束。

验收检查产品主体，而不只检查泡沫等动作：对照首帧、切镜前后、尾帧，并在可疑消失/遮挡区间密集取帧。指定持续出现的产品发生消失、被裁出、遮住主标识或变成另一个SKU时，撤销视觉通过，归档退回版本；网页能播放和文件校验一致不能替代此项。


## 拿出、拾起和递交道具：先交代来源，再展示结果

当人物要从袋、口袋、桌面拿产品，或用户反馈“凭空出现/掏出不自然”时，检查来源状态与抓取过程；不把所有产品口播改成拿取镜头。

- 记录物体初始位置、尺寸、承托物、哪只手执行、另一只手持有什么。起始画面应让观众知道道具在哪里；若来源原本在画外，用合理换角度交代袋口/桌面，而不是在前段已经清楚展示的空桌或手中突然补盒。
- 修复拿取镜头时，同时检查前一段实际画面。新增包、桌面或口袋等来源道具，必须在前段已经建立，或通过有空间依据的揭示镜头进入；不能仅用“原来在画外”解释已展示区域突然多出的包。若原场景没有合理来源，连同前段一起修，并核对手机、坐姿、持物手和机位。共用一张参考图也不代表两段连续，必须比较实际使用的前段尾帧与后段首帧及切点前后动作。
- 关键事件是伸手→接触→手指闭合抓稳→离开承托→抬起展示。物体受力后才移动；离开袋口时遮挡逐渐解除，袋内不能留下第二盒，手机不能变成商品。根据物体重量和距离安排动作时长，不能把完整拿取挤进一句已满的对白中。
- 条件图必须与动作起点一致。“空手人物尾帧＋已举盒母版”只能帮助身份/外观，不能证明模型生成过抓取；不要再把已举盒图当唯一动作参考。优先明确来源的起始图；终态参考仅用于握法/方向，不让模型从终态直接开场。
- 复杂拿取不稳定时，补一条能看到来源、接触和抬起的连续动作镜头，再接展示/对白；保持手、盒方向与空间一致。允许有动机的切近，但不得恰好用切镜掩盖缺失的接触或物体生成。
- 验收重点看接触前后、遮挡解除和切点附近连续帧，以及原速动作。只比较首尾或看尾帧拿着正确盒子不能通过。重复物体、无抓握即移动、手穿袋/盒、来源无法解释均需重做，并保留失效条件与修正版证据。

## 多段衔接看似掉帧或变速

用户说“帧率不一样”时，先分别核对原片、交付段、合成片的实际帧时间戳、平均帧率和时基；标签同为24fps不能证明运动平滑。还要区分播放器卡顿、重复帧与生成动作节奏差异。

若时间戳恒定，检查切点前后约一秒的运动速度/方向、人物姿态、持物手位置、景别、视线、镜头推拉和说话停顿。固定镜头接突然推近、前段快动作接后段近乎定格，都可能形成“换帧率”的观感。记录具体切点与现象，不把正常表情停顿一律当作丢帧。

按失效原因修：从最终使用片尾选择自然停顿/动作匹配切点；同一连续动作使用真实尾帧及清晰身份母版，防止逐代模糊；需要换景别时用明确切镜而非近似构图的小跳变。缺失动作补拍，镜头速度明显不一致则调整该段生成条件。不要默认全片加速、补帧或长叠化；这些不能补回抓取、步态或角色反应，还可能产生重影和口型偏移。修改后重新检查完整合成片，单段通过不能代替跨段检查。

## 高动态特效动作：弹射、摆荡、腾跃与远近入场

此类素材先按原片拆运动和摄影，再选择工作流；不套日常对白的固定全身、微小动作或慢速平稳模板。夸张动作允许参考所需的幅度与速度，但应保持内部因果：何时施力、附着/支撑何处、为何改变方向、如何缓冲。用户说“蜘蛛侠形式”不自动表示改穿蜘蛛侠服装，先保留其指定角色与动作机制。

- 分别记录主体轨迹、身体姿态和镜头运动。远处发丝→锚点附着→绷紧受力→沿弧线接近→松丝/转向→落地缓冲，与站在门口举手抓线的小幅位移是不同镜头。必须建立远处主体尺度、近处落点、过程中身体收展及景别变化，不能靠将人像匀速放大冒充逼近。
- 参考与用户补充共同决定必需事件。已要求发丝时不能写“already gripping”跳过发射；参考有大幅转向/近前展示时不能全组锁死固定全身机位。不能为了让首尾容易相接，先做一个站定终态再把最重要的入场缩成短弧。
- 动作节点是制作依据，不强制每节点一镜。原片连续摆荡优先保持完整运动；确需拆分时选动作中的匹配切点，保留方向、速度和惯性，不能每段归零站定。首尾帧只约束边界，不代表中间轨迹、速度、姿态受控；普通多图参考不冒称骨骼/轨迹/多关键帧控制。
- 先检查实际运动参考/编辑能力。有参考视频输入可试完整高风险动作，但不得承诺逐帧复刻或仅换外观。原运动符合要求且只改局部时，评估可验证的局部编辑/跟踪合成；遮挡、身体形变和透视无法可靠处理时不能用简单贴图冒充。未验证的姿态/深度/轨迹工具不写成已接通。
- 先试全需求中最难且决定创意成立的动作。蛛丝案例先验证远处起势、发丝、摆荡接近、落地，再做独立取物与口播；取物通过不能证明入场能力。动作试片无需同时叠加无关的长对白、产品大特写与身份条件；按镜头实际需要接入，避免条件冲突。
- 对照同一事件的主体相对尺度、路径、锚点、承力姿态、速度变化、镜头与落点。动作不还原时修改设计/参考/实际条件，不用“有白线、有落地、文字正确”给通过。原速观看仍独立记录，密集帧只用于定位。
