# 连续分段：首尾帧衔接与画质保持

用于同一段连续对白、动作或产品展示因时长拆成多个独立文件的情况。文件独立交付不代表镜头可各自重新开场；合集顺序播放也不能修复画面跳变。不同场景或参考明确切镜的素材按真实切镜处理，不把一个需求的所有视频强制做成同机位长镜头。

涉及接力互动或分镜不足时，先按 [分镜设计与剪辑节奏](storyboard-editing.md) 设计镜头覆盖，再判定每个接点是动作匹配切镜还是同镜头连续分段。

## 先确定连续边界

先按 [分镜与拆分决策](storyboard-editing.md) 确认分段确有用途或技术依据。收到接点割裂反馈时，先判断这个接点是否应该存在；同一短动作接口播且无拆分理由时优先试产整个连续单元，不反复只修尾帧。保留必要特写和真正切镜，不把所有长视频强制变成一镜。

拆段前在清单记录 continuity_group、sequence、previous_segment、transition（continuous 或 cut）及动作/对白边界。连续段锁定人物身份、左右位置、景别、机位、光线、手势、持握产品及包装方向；下一段从上一段结束状态继续，不重新拿产品、重置站位或重复上一句。首尾留出不截字的自然动作余量，不能靠长时间静止掩盖衔接。

对每段明确 first_frame 和 last_frame 目标。连续边界要求“上一段最终采用的尾帧 = 下一段首帧条件”，并核查输出实际相接；预先设计的共同边界帧也须检查上一段真实落点与下一段真实起点。参考原片明确切镜时记录切点及视线/动作承接，不强求两帧像素相同。

## 首尾帧必须真正接入工作流

本节针对确实需要连续边界的分段，不要求所有独立对白都绑定尾帧。普通切镜/独立镜头不得默认复制首帧到尾帧来“保稳定”；相同首尾仅用于有依据的回位或循环。边界应描述自然动作落点；僵硬问题另按 [natural-performance.md](natural-performance.md) 对照验证，不能擅自取消真正连续组的首尾衔接。

检查本机已有工作流、节点输入及实际提交的 API 图是否支持首帧、尾帧和所需对白/音频。Ref2VA 的一般参考图不等于首尾帧约束；清单写了 first_frame/last_frame、提示词写了“接上一段”，都不能证明节点已使用。构建器按 H3 输入字段分别绑定 refs、first_frame 和 last_frame；内置 I2V 只支持首帧，传入尾帧会报错。自定义图必须有可解析的独立条件连线。提交前逐一核对首帧、尾帧及身份参考的实际连线和文件 SHA。

若当前模板不支持所需首尾约束或音频组合，先明确能力缺口并试验兼容的已有工作流，不能静默退回独立参考生成并标为连续。依照当前会话已授权范围选择方案；需要改变用户要求的动作/镜头/对白时再请用户选择。

上一段完成并通过质量及对白边界检查后，才提交依赖其尾帧的下一段。以最终裁切点对应的原生生成帧无损提取 PNG，记录原片 SHA、帧号、时间、裁切映射及 PNG SHA；禁止用网页封面、播放器截图、压缩缩略图或放大后的交付视频充当衔接母版。若调整上一段裁切点或重生成，旧尾帧及所有依赖段须重新核对，不能只替换上游文件后直接交付。

## 不能以连贯换取逐段变糊

保留固定的高质量人物、场景和实际产品母版。尾帧提供姿态与边界约束，母版负责身份和细节基准；只有工作流真实支持时才同时输入，不能为凑参考槽位覆盖首尾帧。每段都对照母版及上一段，不能只与已经退化的最近一段比较。

任何衔接帧出现眼睛/面部变软、手部畸变、产品标识损坏，停止向下传播；先修复或重生成上游边界，并重新核对身份和动作。必要时从母版重建共同边界后重做相邻段，不能直接换下一段首帧而制造新跳变。单纯 PNG 重存、放大、锐化或提高码率不能算恢复细节。

同一连续组保持原生尺寸、帧率、画幅和可比生成质量，不为后段提速降低参数。确需调整时用代表段验证后统一处理；原生576×1024放大到720×1280须如实记录。所有交付从各自原生结果一次编码，不由已编码的交付文件再次转码传递；超分/修脸需复核身份与闪烁，不能宣称无损恢复。

## 两项分别验收，均通过才交付

1. 连续性：并排检查每对相邻段的实际末帧/首帧，再以正常速度查看接点前后约0.5–1秒，运动复杂处扩大范围。检查姿态、视线、手和产品位置、运动方向/速度、曝光和色彩，听查对白重复、漏字、截音及突兀长停顿。静态首尾相同不等于动作速度连续。播放器加载停顿与源视频画面跳变分别记录。
2. 清晰度：按 [sharpness-quality.md](sharpness-quality.md) 检查每段首/中/尾的双眼、脸和产品局部，按可比尺度对照固定母版与组内基准；全帧锐度分数不代替局部验收。后段明显退化时标记不通过，阻止其继续成为下一段参考。

参考和候选还需按 [natural-expression.md](natural-expression.md) 对齐关键事件的用时：相接画面相同但动作突然变慢/停住再启动，仍属未通过。

清单保存 continuity_status、sharpness_status、首尾帧路径/SHA和接点检查证据。缺证据时标待复核；仅有 ASR、编码检查或顺序播放通过不能标连续性通过。允许做内部接点预览验收。原分段保留，当前用户要求同需求完整预览时，按 [可选同步约定](workbench-sync.md) 交付；其他任务按原需求交付独立文件。最终按实际sequence检查完整时间线。


## 走近接介绍与触碰

走近接介绍/触碰时，额外核对前景听者的朝向与顺序。上一段前景背面、下一段突然全部正面，同时施动者尺度和距离跳变，即使两段各自正确也不能当作连续。需要连续的段边界使用实际原生尾帧约束新段；有意改机位时，优先在可辨认的同一次伸手/接触动作中切入对应特写，而非人物停着时同时改变所有空间关系。对白跨动作切点保存明确的音轨来源和词时间窗；不能重复介绍，或将画外音配给无关嘴动。


## 实施与返修顺序

- 先选接法：同一机位、同一次未完成动作使用实际尾帧续拍；景别需要变化时做动作匹配切镜。首尾帧解决空间接续，分镜解决信息表达，两者不可互相替代。
- 锁定上一段最终剪辑终点，再提取其原生尾帧。下一段首帧接这张图，尾帧设计为下一动作的合理落点，例如双脚站稳后伸手，而不是重复起步或同姿势冻结。把起点、目标落点、时长与运动路径一起审核；距离太远却限时过短会瞬移，简单动作给太长则像慢放。
- 尾帧图也要核对接触对象：手应到指定人物和身体部位，不能碰到邻人、触角或悬在空中就算完成。若生成的终点错误，不能靠首尾相同宣布通过；返修终点，或在已形成的伸手动作中切到确实拍到正确接触的近景，保留随后反应。
- 输出到达端点只是检查之一。以两段实际采用片段制作接点预览，检查最后一步→站稳→伸手→接触→受方反应的完整因果链；除位置/大小还看运动速度、脚底支撑、眼神和前景人物朝向。不要用叠化、冻结帧或整体加速掩盖错误动作。
- 对白可以跨动作切镜，但保存音频来源、说话人、词时间窗；出画后的声音可继续，换成听者画面时不能让听者跟着说。音画独立剪辑后重新检查漏字、重复、截尾和可见口型时序。
- 同一镜头被多个需求复用时，按参考文件、角色身份、台词、动作与时间窗确认一致，再传播修正，并记录每条需求的依赖和新 SHA。产品不同的比较旁白仍保留各自音轨；不能把修好一条误认为所有复用需求已交付。


## 产品取出与互动状态不能重置

取出、插入、递接这类遮挡动作，除首尾位置还应记录物体状态链：包装已打开 → 手指夹住目标 → 物体经开口逐渐显露 → 完全离开包装并保持。始终是同一物体，数量、卷边/薄膜结构、尺寸及握持点一致；两张端点图好看不代表中间没有穿过袋面、凭空出现、变成白色实体或掉失。先核对清晰产品实图，再用可辨认开口和遮挡关系的近景试拍；不能用错误结果的最后一帧继续传播。画面切为手部产品近景时，可沿用本需求英雄音轨作画外音，不让无关人物代说。

接力角色段落需保存事件状态：已入场的角色不因新文件又退回远处重新入场；举臂展示后切特写，再切回应承接收臂/接触和听者反馈，之后才退出。接点检查覆盖上一段最后一个完整动作与下一段第一个完整动作，不能只比较最后/最前一帧。关联需求复用同一错误段时分别修复并记录，不因一个需求的措辞不同就漏掉相同画面问题。


串联前还需统一实际编码格式：同分辨率/24fps并不足够。例如一个来源为 yuv420p10le，另一个来源为 yuv420p；直接流复制混合可能导致播放器兼容问题、抽帧滤镜中途重置，仅输出最后一段。交付中间片从各自原生文件统一像素格式、色彩标记和时间基，再串联；检查实际解码帧数及首/中/末内容，不能只读容器第一条流的参数。若选通用网页H.264，显式输出兼容的yuv420p，并保留原始10-bit源文件；转换不能冒称无损。发现抽帧只剩后段，先排查中途格式变化，不能误判前段不存在。


## 相邻段的商品尺寸与实体结构

当同一件商品跨段持续握持，按清晰实物图锁定正面长宽比、侧面厚度和包装数量；用商品相对手掌、脸或躯干的尺度比较接点，区分相机推近、物体朝向带来的合理透视变化与商品本身缩小/变扁。不同机位不要求像素高度相等，但不能在同一握持关系中把长盒变短盒、立体盒变薄片。没有实测尺寸时不编造厘米数。

返修先检查上一段实际尾帧的产品是否正确，再决定修哪一侧。下一段参考须保留合格盒体的比例、握持点和支撑关系；商品身份相同或颜色相近不能代替尺寸一致。修一段后检查所有相依接点，直到重新接入尺寸正确的稳定状态，不能把原来的缩放跳变移到后一个切点。验收覆盖转动、遮挡和单手/双手转换；禁止单独放大整帧来修产品比例，或只改提示词而不核对实际输出。

## 边界不是表演母版

连续性还须遵守 [制作约定](production-contract.md) 的三类参考分工：原片负责表演依据，清晰母版负责身份，实际剪辑尾帧负责边界。普通多图参考不是硬首尾帧；记录实际接入类型。上一段的笑容、闭眼或失焦不能变成下一段默认状态，修接点同时复核情绪触发、产品相对手掌尺度和原生清晰度。
